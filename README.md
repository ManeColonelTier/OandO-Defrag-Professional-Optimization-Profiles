## Usage

### For Standard Defragmentation:
1. Launch O&O Defrag Professional and open the **Profiles** section.
2. Import the provided profile file (`.ood`) via **File** → **Import Profile**.
3. Select the appropriate profile for your drive type (SSD, HDD, gaming, etc.).
4. Choose the target drives and click **Start** to begin optimization.
5. Monitor the defragmentation process and review the post-operation report.

### For SSD Optimization:
1. Load the "SSD Optimization" profile.
2. Ensure that TRIM is enabled and properly configured.
3. Run the profile to perform SSD-specific optimization and space consolidation.
4. Avoid excessive defragmentation; the profile is set for optimal SSD maintenance frequency.
5. Review drive health using the included monitoring templates.

### For Game Drive Optimization:
1. Select the "Gaming Drive" profile for installed game drives.
2. This profile focuses on file access patterns typical for gaming.
3. Run the optimization to reduce game load times.
4. Use the "Single-File/Folder Focus" templates for specific game directories if needed.
5. Schedule the profile to run weekly for consistent performance.

### For Automation:
1. Navigate to the `automation-scripts` folder.
2. Edit the script variables (drives, profiles, schedule, etc.) as needed.
3. Run the script manually or create a scheduled task using the provided task scheduler setup guide.
4. The script will execute the defragmentation and generate a log file.
5. Review logs in the `logs` directory for performance insights.

### Reporting & Monitoring:
1. Load the reporting profile from the templates.
2. Configure email or file output settings for post-defragmentation reports.
3. Run the profile to generate detailed reports on fragmentation and optimization.
4. Use the performance monitoring templates to track changes over time.
5. Adjust optimization frequency based on report findings.
